# ImgDo

VS Code / Cursor / Trae 图片工具插件

助力项目优化！！！

快捷键：Command + Shift + 9



- 项目图片自动查找一键压缩
- ICO 快捷生成
- Base64图转化查看

## 功能介绍

### 图片压缩

- 扫描工作区 / 指定文件夹中的 JPG、PNG、WebP
- 批量压缩，支持预览对比、调整目标宽度
- 一键替换原图（可选备份到 `.backup`）
- 不足最小压缩幅度时自动降档重试
- 尊重 `.gitignore`，并跳过常见构建目录（如 `node_modules`、`.git`、`dist` 等）

### ICO 生成

- 从本地图片生成 ICO 文件
- 支持裁剪与保存到源图同目录

### Base64 转化

- 图 → Base64
- Base64 → 图

## 打开方式

任选其一即可唤起（默认进入**图片压缩**）：


| 方式           | 说明                                |
| ------------ | --------------------------------- |
| Activity Bar | 点击左侧 **ImgDo** 图标，建议固定            |
| 快捷键          | `Ctrl(或Cmd) + Shift + 9`          |
| 命令面板         | `Cmd/Ctrl + Shift + P`，搜索 `ImgDo` |
| 资源管理器        | 右键文件夹 → **在图片压缩中打开**              |


面板顶部可切换：**图片压缩** / **ICO 生成** / **Base64 转化**。

## 快捷键


| 操作     | Windows / Linux    | macOS             |
| ------ | ------------------ | ----------------- |
| 打开图片压缩 | `Ctrl + Shift + 9` | `Cmd + Shift + 9` |


可在 VS Code **键盘快捷方式**中搜索「打开图片压缩」修改。

## 命令


| 命令                    | 说明             |
| --------------------- | -------------- |
| `ImgDo: 打开图片压缩`       | 打开面板并进入压缩      |
| `ImgDo: 在图片压缩中打开`     | 以当前文件夹为扫描根打开压缩 |
| `ImgDo: 打开 ICO 生成`    | 打开面板并进入 ICO    |
| `ImgDo: 打开 Base64 转化` | 打开面板并进入 Base64 |
